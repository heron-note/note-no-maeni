========================================
noteのまえに - キャラクター制作ガイド
========================================

このガイドは、アプリに登録するキャラクター画像を
自分で用意するための情報をまとめたものです。
キャラクターのデザインはあなたが自由に決めてください。
動物でも、人でも、物でも、抽象的な形でも構いません。

========================================
必要なファイル
========================================

キャラクター1体につき、以下4枚の画像が必要です。

  normal.svg（またはnormal.png）
    使用場面: ホーム画面（毎日最初に表示される）
    演出:     待機・ニュートラル。毎日見ても飽きない表情。

  write.svg（またはwrite.png）
    使用場面: 「書く」を選んだ直後
    演出:     背中を押す・応援。前向きで力強い。

  rest.svg（またはrest.png）
    使用場面: 「休む」を選んだ直後（スタンプ画面）
    演出:     一緒に休む・脱力・ほっとする。
              「休むことは正しい」という空気感。罪悪感ゼロ。

  watch.svg（またはwatch.png）
    使用場面: 今日すでに記録済みの画面（おかえり）
    演出:     穏やかに見守る・受け入れる。
              何があっても歓迎する温かさ。

配置場所:
  public/assets/images/characters/<キャラクターID>/normal.svg
  public/assets/images/characters/<キャラクターID>/write.svg
  ...（以下同様）

キャラクターIDと表示名は src/characters.ts に登録してください。

========================================
画像の技術仕様
========================================

推奨サイズ:  200×220px（縦長）
背景:        透明（必須）
形式:        SVGまたはPNG

SVGの場合:
  <svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 200 220">
    ...
  </svg>

PNGの場合:
  src/characters.ts の charImgPath 関数の拡張子を変更:
  return `assets/images/characters/${charKey}/${stateKey}.png`

========================================
制作方法（どれか一つを選ぶ）
========================================

【方法A: 自分でイラストを描く】
上記仕様を満たせば何でも可。
Illustrator / Figma / Procreate 等で制作後、
SVGまたは透過PNGで書き出す。

【方法B: AI画像生成ツールで作る】
Midjourney / DALL-E 3 / Stable Diffusion / Adobe Firefly 等を使う。

プロンプトの組み立て方:
  1. キャラクター説明（あなたが決める）
  2. ステートごとのポーズ・表情指示（下記テンプレート参照）
  3. 出力スタイル指定（下記テンプレート参照）

英語プロンプト テンプレート:
  [キャラクター説明], [ポーズ・表情], [スタイル指定]

スタイル指定（末尾に付ける）:
  transparent background, full body, no text, no watermark,
  simple clean illustration

ステートごとのポーズ・表情:
  normal: calm neutral expression, relaxed natural pose
  write:  motivated forward-leaning pose, encouraging expression
  rest:   relaxed droopy expression, limp or slouched body, carefree
  watch:  warm gentle gaze, open welcoming pose, soft smile

【方法C: LLMにSVGコードを書かせる】
Claude等のLLMにSVGを生成させる。
以下のプロンプトをそのまま使い、
[キャラクター説明]と[ステート指示]を自分のキャラクターに合わせて書き換える。

- text要素は最小限（演出記号のみ）

========================================
品質チェックリスト
========================================

4枚完成後に確認:
[ ] 同じキャラクターに見えるか（色・形・比率が統一されているか）
[ ] 背景が透明か（白ベタになっていないか）
[ ] rest が暗い・落ち込んだ印象でなく「ほっこり・充足」に見えるか
[ ] watch が「監視・圧」でなく「温かく迎え入れる」雰囲気か
[ ] スマートフォン画面（375px幅）で小さすぎず大きすぎないか
[ ] 4ステート並べたとき統一感があるか
