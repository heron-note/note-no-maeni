========================================
noteのまえに - キャラクター生成プロンプト集
========================================

【アプリ概要】
note.com ユーザーの書くプレッシャーをやわらげるメンタルサポートPWA。
「今日は書く？休む？」を毎日選べる。
トーン: 穏やか・やさしい・ちょっとユーモラス

【技術仕様（全キャラ共通）】
- ファイル形式: SVG（またはPNG）
- サイズ: 200×220px
- 背景: 透明
- 頭身: 2〜2.5頭身（頭が大きい）

【必要なステート（各キャラ4枚）】
normal  通常待機。ホーム画面に毎日表示。
write   「書く」を選んだとき。背中を押す・応援。
rest    「休む」を選んだとき。一緒に休む・ほっとする。
watch   今日の記録済み画面。穏やかに見守る・おかえりの雰囲気。

========================================

に変更する。

========================================
品質チェックリスト
========================================

各キャラクター完成後に確認:
[ ] 同じキャラクターの4ステートで体型・色が統一されているか
[ ] 3キャラクター間でサイズ感が揃っているか
[ ] 背景が透明か（白ベタになっていないか）
[ ] rest が「ネガティブ」でなく「ほっこり」に見えるか
[ ] watch が「圧」でなく「温かみ」に見えるか
[ ] 375px幅のスマホ画面で小さすぎないか
