# 『noteのまえに』開発・実装仕様書

## 1. プロジェクト概要

* **アプリ名**：『noteのまえに』
* **サブコピー**：書く日も、読む日も、休む日も。
* **目的**：スマホでnoteを開く「直前」に立ち上げ、今日のnoteとの付き合い方を自分で選ぶ「心の安全基地（メンタルサポーター）」アプリ。
* **コア思想**：
* 「成果（何文字書いたか）」ではなく「自分で今日どう過ごすかを選択できたこと」そのものを全肯定する。
* 「連続投稿の呪縛」や「白紙恐怖症」からユーザーを解放し、脱落を防ぐ。


* **動作・配信形態**：PWA（Progressive Web App）
* アプリストアを経由せず、スマホの「ホーム画面に追加」して完全独立アプリとして使用。
* サーバー不要（完全フロントエンド・Static Hosting）。`localStorage` によりオフライン＆爆速起動。

## 3. 各選択肢の詳細挙動

### 🟥 【書く】（アウトプット：1行でも書く）

* **相棒リアクション**：背中をそっと押すセリフ＋イラスト表示。
* **誘導**：画面内に `[ noteを開く ]` ボタン（`[https://note.com](https://note.com)` へ遷移）を表示。

### 🟩 【読む】（インプット：1記事でも読む）

* **相棒リアクション**：肩の力を抜かせるセリフ＋イラスト表示（「スキを押せ」等の行動強制はしない）。
* **誘導**：画面内に `[ noteを開く ]` ボタン（`[https://note.com](https://note.com)` へ遷移）を表示。

### 🟦 【休む】（「投稿しなきゃ」のプレッシャーからの解放：看板機能）

1. **演出**：「note休もっ化計画」丸型スタンプが画面上に押し出される。
* **SE**：「ドンっ！」という重厚な打刻音（フリー素材音声）を即座に再生。
* **CSSアニメーション**：拡大（`scale(1.4)`）➔ 叩きつけ縮小（`scale(0.85)`）➔ 反動定着（`scale(1.0)` / 若干傾く）。


2. **コンテンツ**：パロディ「休もっ化宣言」テキスト（後述）を固定データからランダム抽出して表示。
3. **2段階の逃げ道選択**：
* **`[ これを投稿する ]`** ➔ テキストをクリップボードに自動コピーし、`[https://note.com](https://note.com)` へ遷移（連続投稿を守りたい人向け）。
* **`[ 今日は何もしない ]`** ➔ noteへは行かず、そのまま画面完了（完全に離れたい人向け）。

### ② ガチャ（相棒の状態・セリフ）抽出一覧

選択時、相棒の状態が以下の確率で抽出される。

* **通常セット（80%）**：日常的な寄り添い・共感・労わり
* **ちょっと珍しいセット（15%）**：季節感、時間帯、ユニークな視点
* **レアセット（5%）**：クスッと笑える演出や特殊ポーズ（隠し要素）

## 5. UI / PWA 切り替え仕様

* **PWAモード（「ホーム画面に追加」後）**
* `display-mode: standalone` で画面全体（アドレスバーなし）表示。
* ヘッダーのインストール案内は完全に非表示。


* **Webブラウザ表示時（初回・ブラウザアクセス時）**
* 基本機能（3択＋カレンダーテスト）はそのまま試用可能。
* 画面端に小さな案内バナーを表示：
> *「ホーム画面に追加すると、アドレスバーが消えて『自分だけの相棒アプリ』になります。[手順を見る]」*


* 「手順を見る」タップで、iOS（Safari）/ Android（Chrome）それぞれのホーム画面追加3ステップ案内をポップアップ。

## 6. アプリ必要アセット（素材一覧）

1. **ホーム画面アイコン**：1点（PWAインストール時にスマホのホーム画面に並ぶ相棒の顔）
2. **相棒キャラクター画像**：計10〜15点程度（書く/読む/休む/見守り 各表情）
3. **「note休もっ化計画」ロゴ**：丸型スタンプ風透過画像（PNGまたはSVG）
4. **効果音（SE）**：打刻音・太鼓音（フリー素材 `.mp3` / `.ogg`）
